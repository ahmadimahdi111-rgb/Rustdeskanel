# به‌روزرسانی پنل

نسخهٔ ۳.۲.۰ شامل منوهای موضوعی، جست‌وجو و فیلتر سیستم‌های مقصد، انتخاب تاریخ با تقویم شمسی یا میلادی و امکان تغییر رمز کاربران توسط مدیر است.

برای نصب تازه از `install.sh` استفاده کنید. برای ارتقای نصب موجود از بستهٔ ZIP، آن را در سرور استخراج و اجرا کنید:

```bash
cd /home/rustdesk/rustdesk-server/panel
sudo bash upgrade.sh
```

به‌روزرسانی آنلاین نیز با انتشار این نسخه در شاخهٔ `main` مخزن فعال می‌شود. اطلاعات ورود، پایگاه‌داده و گواهی TLS حفظ می‌شوند.
