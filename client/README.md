# کلاینت ویندوز

`HCU-RemoteClient.hta` یک پنجرهٔ دسکتاپ ویندوزی است. با دوبارکلیک اجرا می‌شود، با همان حساب پنل وارد می‌شود، شناسه‌های دلخواه را برای حساب کارشناس ذخیره می‌کند و RustDesk نصب‌شده را برای اتصال باز می‌کند. اتصال مقصد باید در RustDesk تأیید شود.

این نسخه واسط ویندوزی است، نه فایل اجرایی مستقل RustDesk. RustDesk 1.5.3 یا سازگار باید از قبل نصب و با ID Server، Relay و کلید عمومی دانشگاه پیکربندی شده باشد.

برای ثبت خودکار نام و IP مقصد، روی رایانه مقصد `HCU-DeviceAgent.ps1` را اجرا کن؛ کلید Agent را از تنظیمات مدیر پنل بگیر. برای اجرای Agent بعد از ورود ویندوز، PowerShell را با دسترسی مدیر باز کن و اجرا کن:

```powershell
powershell -ExecutionPolicy Bypass -File .\HCU-DeviceAgent.ps1 -InstallTask
```

Agent شناسه RustDesk محلی، hostname و IP را هر پنج دقیقه ثبت می‌کند. در نوبت نخست، کلید را درخواست می‌کند و در پوشه کاربر ذخیره می‌کند.
